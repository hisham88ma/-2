# Phonebook App

تطبيق دليل الهاتف هذا مكوّن من جزأين:

- `phonebook-backend`: خادم Express بسيط يقدم بيانات الأسماء والأرقام.
- `phonebook-frontend`: واجهة React/​Vite للتعديل والبحث في دليل الهاتف.

## تشغيل المشروع

1. افتح المجلد `phonebook-backend` وثبّت الحزم:
   ```bash
   npm install
   npm start
   ```
2. افتح المجلد `phonebook-frontend` وثبّت الحزم:
   ```bash
   npm install
   npm run dev
   ```

## الميزات

- عرض قائمة الأرقام الحالية
- إضافة شخص جديد مع اسم ورقم
- تحديث رقم شخص موجود
- حذف شخص من القائمة
- بحث فوري بالأسماء

## ملاحظات

- لا يحتوي المشروع على بيانات ملكية شخصية.
- يمكن تشغيل الخادم على `http://localhost:3001` والواجهة على `http://localhost:5173`.
